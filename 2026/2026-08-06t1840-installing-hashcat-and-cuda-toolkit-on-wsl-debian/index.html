WSL Debian系统安装Hashcat及Cuda

Written by sinowrt with ♥ on August 6, 2026 in WSL

0x00 安装环境

宿主机：windows 10

虚拟系统：Debian

目标hashcat版本：v6.2.3（项目地址）

目标cuda-toolkit版本：12.8

0x01 安装hashcat

步骤1：安装依赖及pyenv

# 安装构建python所需依赖库
sudo apt install libbz2-dev libssl-dev libncurses5-dev libffi-dev libreadline-dev libsqlite3-dev liblzma-dev
# 安装pyenv
curl https://pyenv.run | bash

步骤2：使用pyenv安装python

# 安装Python 3.12或更新版本
pyenv install 3.12
# 检查安装的版本
pyenv versions
# Example:
# * system
#   3.12.11

步骤3：克隆Hashcat仓库到本地

$ git clone https://github.com/hashcat/hashcat.git -b v6.2.3
$ cd hashcat

步骤4：编译Hashcat

make clean && make

步骤5：安装Hashcat

$ make install

0x02 安装 CUDA Toolkit

# 下载安装官方的软件源密钥环：
wget https://developer.download.nvidia.com/compute/cuda/repos/wsl-ubuntu/x86_64/cuda-keyring_1.1-1_all.deb
sudo dpkg -i cuda-keyring_1.1-1_all.deb
# 更新软件列表
sudo apt-get update
# 安装 CUDA Toolkit
sudo apt-get -y install cuda-toolkit-12-8

0x03 验证Hashcat是否识别到显卡

hashcat -I

# 输出如下信息即为识别成功
# hashcat (v6.2.3) starting in backend information mode

# clGetPlatformIDs(): CL_PLATFORM_NOT_FOUND_KHR

# CUDA Info:
# ==========

# CUDA.Version.: 13.2

# Backend Device ID #1
#   Name...........: NVIDIA GeForce RTX 5060
#   Processor(s)...: 30
#   Clock..........: 2535
#   Memory.Total...: 8150 MB
#   Memory.Free....: 7020 MB
#   PCI.Addr.BDFe..: 0000:07:00.0

0x04 安装中遇到的问题

在安装hashcat的步骤2中，使用pyenv安装3.12版本的python时，出现以下报错：

解决办法：运行以下命令安装C语言编译器

libbz2-dev libreadline-dev libsqlite3-dev wget curl llvm \
libncursesw5-dev xz-utils tk-dev libxml2-dev libxmlsec1-dev \
libffi-dev liblzma-dev
